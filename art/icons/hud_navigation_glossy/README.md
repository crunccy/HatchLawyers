# Hatch a Lawyer HUD icons — glossy revision

Sixteen original, transparent PNG icons for the game's HUD navigation. Each PNG is 1254 × 1254 pixels. Open [review.html](review.html) or [overview.png](overview.png) to review the complete set.

| Main navigation | Additional icons |
| --- | --- |
| Daily Gift, Goals, Lawyers, Shop, Rebirth, Travel | Settings, Codes, Index, Achievements, VIP, Upgrades, Money, Merge, Eggs, Friends |

This revision keeps the original glossy direction. Daily Gift is yellow; Lawyers has a refined character; Rebirth, Travel, Settings, and Merge have quieter effects. The individual files are in [`icons/`](icons/), with names matching their HUD uses. `manifest.json` lists the files and revision status.

These are art assets for review. They have not been imported into Roblox Studio or wired into the HUD.
