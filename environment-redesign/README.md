# Environment redesign — floating-island universe (Blender only)

crnuch's brief (2026-10-18): replace the map with one central hub island and six egg-world islands. They are
designed, modeled and reviewed **in Blender first**: no Studio, gameplay code or live-map changes until crnuch
approves integration. Every model follows the studded-brick rule (docs/ART_STYLE_STUDS.md: real raised studs, 1-stud
pitch, Roblox's own stud shape).

## Layout
```
environment-redesign/
  01_AUDIT.md                     Stage 1
  references/                     approved mockups (put crnuch's reference images here)
  central_hub/blockout/           Stage 2: hub_blockout.py (source), .blend, hub_layout.json, LAYOUT.md, renders/
  <island>/                       later: one folder per island, each its own .blend (independent, exportable)
```
Each island is its own `.blend` and collection, so new islands can be added without touching the others.

## Rebuilding
Every `.blend` and render is generated by the `.py` next to it:
```bash
/Applications/Blender.app/Contents/MacOS/Blender -b --python environment-redesign/central_hub/blockout/hub_blockout.py
```
(append `-- norender` to save only the `.blend` and the layout JSON).

## Large files
Git LFS isn't installed on crnuch's Mac. While files stay small (blockout `.blend` 0.5 MB, JPEG renders) they go in
plain git. Before any `.blend` passes ~20 MB, both machines install Git LFS and track `*.blend`. Until then, the
scripts are the source of truth and big `.blend`s can stay local.
