Each island is its own `.blend` and collection, so new islands can be added without touching the others.

**Everything is studded voxel (crnuch's call 2026-10-19: "i genuinely mean everything").** The kit builds every
round, sloped or polygonal shape as stepped bricks on the 1-stud grid (`hl_kit.Mesh`: cyl, ring, cone, sphere, prism,
wedge, pyramid, ring_v, disc_v), and `K.studs_done()` is a pass that puts raised studs on every exposed top of every
object, bosses and statues included. Each object carries its own stud instancers, so anything that moves keeps
its studs. All five areas were rebuilt and re-rendered with it on 2026-10-19.

## Rebuilding
Every `.blend` and render is generated by the `.py` next to it:
```bash
/Applications/Blender.app/Contents/MacOS/Blender -b --python environment-redesign/central_hub/blockout/hub_blockout.py
"/c/Program Files/Blender Foundation/Blender 5.2/blender.exe" -b --python environment-redesign/ocean_shore/os_build.py   # (mr.robe's Windows PC, Git Bash)
```
(append `-- norender` to save only the `.blend` and the layout JSON).

## Large files
Git LFS isn't installed on crnuch's Mac. While files stay small (blockout `.blend` 0.5 MB, JPEG renders) they go in
plain git. Before any `.blend` passes ~20 MB, both machines install Git LFS and track `*.blend`. Until then, the
scripts are the source of truth and big `.blend`s can stay local.

**Previews (crnuch's call 2026-10-19):** islands ship static renders + the animated .blend only - no ambience stills
or MP4 clips (they cost ~20 min per island).

## Notes for Stage 7 (integration)
- **Boss areas:** each island doc gives a suggested boss area (the box the boss may stand in). Today BossService
  derives that area from the zone's `Bounds` shrunk by `Config.Bosses.Margin` (40 along / 10 across), and clamps
  every Slam landing and Line roll to it. On an island the zone's Bounds is the whole island, so integration should
  set each boss's arena box directly (e.g. a per-boss `Arena`) rather than tune Bounds + Margin. (Found 2026-10-19:
  the docs' "suggested Bounds" for Briefcase Bay and Pet Park mean this area too.)
- **Moving scenery** (turning signs, floating cubes, clouds) is client-only motion, like `WorldLife`; its studs ride
  with it (each object owns its stud instancers, `K.studs_done`).


## Building into the place (2026-10-19)
Every island build script can also be exported as Roblox PARTS: `kit/hl_export.py` records every brick the build
makes (since the voxel kit, 2026-10-19, every round / sloped shape IS bricks, so the export is all stepped boxes: no
Cylinder, Ball or WedgePart parts), sign text → SurfaceGui text and statues → their own blocks; studs and bosses are
left out. `kit/export_island.py` runs the build with it, saving nothing to the island's .blend / layout JSON:
```bash
"/c/Program Files/Blender Foundation/Blender 5.2/blender.exe" -b --python environment-redesign/kit/export_island.py -- ocean_shore os_build.py OceanShore
```
→ `tools/zones/redesign/<Island>.json` (Roblox space). In Studio (Edit mode, the JSON served on 8766),
`tools/zones/BuildRedesignIsland.lua` builds it into `Workspace.WorldRedesign.<Island>` (one Model per Blender
object, BrickStuds plastic, Neon glows, Glass water without collision; ZFight passes at the end). Re-export + rebuild
an island after changing its Blender script. Where they stand: the hub at (3600, 150, -1200), the egg islands on a ring
of 760 round it (Briefcase Bay NE, Pet Park E, Brainrot Zone SE, Food Court SW, Ocean Shore W, Space Base NW).
Parts in the place now (built 2026-10-19 from the PRE-voxel exports): hub 27.6k, Briefcase Bay 11.5k, Pet Park 13.9k, Brainrot
Zone 10.9k, Food Court 13.9k, Ocean Shore 17.1k, Space Base 13.3k. The voxel exports in `tools/zones/redesign/` (2026-10-19,
all bricks) are bigger: hub 37.0k, Briefcase Bay 18.2k, Pet Park 19.9k, Brainrot Zone 18.2k, Food Court 21.9k, Ocean Shore
25.9k, Space Base 23.4k (165k vs 108k): the place is NOT rebuilt from them yet - crnuch's call 2026-10-19: leave it
until parts vs meshes is decided.
Meshes named `Sky_*` (far Blender-only backdrops like Space Base's starfield) are not exported.
Admin `/island <name>` (AdminCommands) drops you on an island's south side in a playtest.
